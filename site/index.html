ZipMount

Open an archive as a drive.

ZipMount mounts zip, 7z, tar and tar.gz archives as ordinary Windows drives: read-only, and without extracting anything. Browse them in File Explorer, search them, open files from any program. The archive stays a single file.

Download for Windows Source code

Latest release · 64-bit Windows 10 (2004 or later) or Windows 11 · WinFsp included · free and open source (GPL-3.0)

What you get

7-Zip and the built-in Compressed Folders show an archive in their own window. ZipMount gives it a drive letter, so every program can read it through an ordinary path.

Explorer

A real drive letter

The archive shows up as Z: or any free letter. Navigation, filename search, previews and copying out all work.

Lazy

Nothing is extracted

Files are decompressed only when a program reads them. A multi-gigabyte archive opens in a fraction of a second.

One click

Context menu

Right-click an archive and choose Mount as a drive. It opens in File Explorer; right-click the drive to unmount it.

Search

Fast content search

zipmount grep searches inside a zip at gigabytes per second, without going through the file system.

Passwords

Encrypted archives

Asks for the password when it is needed. It is never taken from the command line, so it stays out of shell history.

8 languages

Speaks your language

English, Russian, Chinese, Japanese, Korean, Portuguese, Spanish and German, picked from your Windows settings.

How it works

The installer brings everything, including WinFsp, the driver behind rclone, sshfs-win and Google Drive for desktop.

  1. InstallRun ZipMount-Setup.exe and confirm the prompt. WinFsp is installed only if it is missing.
  2. MountRight-click a .zip, .7z, .tar or .tar.gz and choose Mount as a drive, or use the command line.
  3. Use itOpen, search and copy files on the new drive. Unmount when you are done; the archive is never modified.

From the command line

Everything the menu does, and a few things it does not.

# mount, then use Z:\ from any program
zipmount mount D:\data\archive.7z Z:

# search by content, without mounting
zipmount grep D:\data\logs.zip "timeout"

# check every entry against its stored CRC32
zipmount verify D:\data\archive.7z

zipmount unmount Z:

How fast

A 239 MB zip holding 2 GB of text in 10,411 files, on 16 cores.

About the Windows warning

The installer is not signed with a paid code-signing certificate yet, so Windows may show “Unknown publisher” or a SmartScreen warning. Choose More info → Run anyway if you trust the source.

To check the download, compare it with SHA256SUMS.txt from the same release, or ask GitHub to confirm it was built from this repository: gh attestation verify ZipMount-Setup-<version>.exe --repo marlogg74mp/zipmount
