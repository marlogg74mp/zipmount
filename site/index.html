Open an archive as a drive.

ZipMount mounts zip, 7z, tar and tar.gz archives read-only, without extracting anything: as a drive letter on Windows, as a folder in the file manager on Linux and macOS. Browse them, search them, open files from any program. The archive stays a single file.

What you get

7-Zip and the built-in archive viewers show an archive in a window of their own. ZipMount mounts it, so every program can read it through an ordinary path.

Mounted

A drive, or a folder

Z: on Windows; ~/ZipMount/<name> on Linux and macOS, in the file manager's sidebar. Navigation, search, previews and copying out all work.

Lazy

Nothing is extracted

Files are decompressed only when a program reads them. A multi-gigabyte archive opens in a fraction of a second.

One click

Context menu

Right-click an archive: Mount as a drive in File Explorer, Mount with ZipMount in Finder, Dolphin or GNOME Files.

Search

Fast content search

zipmount grep searches inside an archive at gigabytes per second, without going through the file system.

Passwords

Encrypted archives

Asks for the password when it is needed. It is never taken from the command line, so it stays out of shell history.

8 languages

Speaks your language

English, Russian, Chinese, Japanese, Korean, Portuguese, Spanish and German, picked from your system settings.

How it works

Each system mounts through what it already has: WinFsp on Windows (the installer brings it), FUSE on Linux, and the built-in NFS client on macOS — no kernel extension, no administrator rights.

  1. InstallThe installer on Windows, Homebrew on macOS, one binary on Linux. Then zipmount shell-install adds the menu item on Linux and macOS.
  2. MountRight-click a .zip, .7z, .tar or .tar.gz and choose the ZipMount item, or use the command line.
  3. Use itOpen, search and copy files. Unmount (or Eject) when you are done; the archive is never modified.

From the command line

Everything the menu does, and a few things it does not.

# mount: Z: on Windows, ~/ZipMount/archive elsewhere
zipmount mount archive.7z

# search by content, without mounting
zipmount grep logs.zip "timeout"

# check every entry against its stored CRC32
zipmount verify archive.7z

zipmount mounts
zipmount unmount archive.7z

About the security warnings

Nothing is signed with a paid certificate yet. On Windows the installer may show “Unknown publisher” or a SmartScreen warning: choose More info → Run anyway if you trust the source. On macOS a downloaded binary has to be allowed in System Settings → Privacy & Security; Homebrew avoids that.

To check a download, compare it with SHA256SUMS.txt from the same release, or ask GitHub to confirm it was built from this repository: gh attestation verify <file> --repo marlogg74mp/zipmount
